# Smart Code Review Agent

**Purpose**: AI-powered automated code review for pull requests

**Location**: Copy these files to your project's `.github/` directory

## Files

1. **smart-code-review.yml** → Copy to `.github/workflows/smart-code-review.yml`
2. **smart_code_review.py** → Copy to `.github/scripts/smart_code_review.py`

## Setup in a Project

```bash
# From your project root
mkdir -p .github/workflows .github/scripts

# Copy workflow
cp ~/claude-config/github-actions/smart-code-review/smart-code-review.yml \
   .github/workflows/

# Copy script
cp ~/claude-config/github-actions/smart-code-review/smart_code_review.py \
   .github/scripts/

# Make script executable
chmod +x .github/scripts/smart_code_review.py

# Add Anthropic API key as GitHub secret
# Go to: Settings → Secrets → Actions → New repository secret
# Name: ANTHROPIC_API_KEY
# Value: your-anthropic-api-key

# Commit and push
git add .github/
git commit -m "feat: Add Smart Code Review Agent workflow"
git push
```

## How It Works

**Triggers**: Runs on every pull request (opened, synchronize, reopened)

**Actions**:
1. Runs static analysis:
   - **Python**: ruff, mypy, black, isort
   - **JavaScript/TypeScript**: ESLint
2. Checks for anti-patterns:
   - N+1 queries (Python/Django)
   - SQL injection risks
   - Missing error handling
   - Console.log statements (JS)
   - `any` type usage (TypeScript)
   - And more...
3. Uses Claude AI to analyze issues and provide insights
4. Posts comprehensive review comment on PR
5. Auto-approves if all checks pass (low-risk changes)

## Anti-Patterns Detected

### Python
- N+1 database queries
- Bare except clauses
- SQL injection risks
- Missing error handling on requests
- Unvalidated user input

### JavaScript/TypeScript
- console.log statements (should use proper logging)
- `var` usage (use `const`/`let`)
- `eval()` usage (security risk)
- `innerHTML` assignment (XSS risk)
- `any` type usage (defeats TypeScript purpose)
- Non-null assertions (`!`)

## Customization

Edit `smart_code_review.py` to:

### Add More Anti-Patterns

```python
ANTI_PATTERNS = {
    'python': {
        # Add your patterns
        'hardcoded_password': r'password\s*=\s*["\'][^"\']+["\']',
    },
    'javascript': {
        # Add your patterns
        'todo_comment': r'//\s*TODO',
    }
}
```

### Adjust Auto-Approve Logic

```python
# Current: Auto-approve if no errors and ≤5 issues
approved = len(errors) == 0 and len(issues) <= 5

# Stricter: Only approve if zero issues
approved = len(issues) == 0

# Looser: Approve if no errors (ignore warnings)
approved = len(errors) == 0
```

## Combining with Coverage Guardian

Use both for comprehensive quality gates:

```yaml
# .github/workflows/quality-gates.yml
name: Quality Gates

on: pull_request

jobs:
  coverage:
    uses: ./.github/workflows/coverage-guardian.yml

  code-review:
    uses: ./.github/workflows/smart-code-review.yml
```

Both must pass before merge!
